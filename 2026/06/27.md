# わかったこと
- フロントエンドからバックエンドへのデータ受け渡しの流れ

① Reactから以下のPOST送信がされると
```
axios.post(
  'https://your-api.onrender.com/signup',
  {
    email: 'user2@test.com',
    password: 'password',
  }
)
```
② EchoはURLとHTTPメソッドを照合して、次の関数を実行する。

```
func (uc *userController) SignUp(c echo.Context) error {
    // POSTされたデータを受け取る処理
}
```
③ HTTPメソッドも一致する必要があります。
```
e.POST("/signup", uc.SignUp)
e.GET("/csrf", uc.CsrfToken)
e.DELETE("/tasks/:taskId", tc.DeleteTask)
```
- `GET /signup` を送っても SignUp は実行されない。POST と /signup の両方が一致したときだけ実行する。
